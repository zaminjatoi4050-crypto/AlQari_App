# AlQariApp — Full Quran Reader & Word Analysis

**This is a full-data project, not a sample-verse demo.** The release workflow downloads the complete Quran corpus, verifies all 114 surahs / 6,236 ayat, downloads the Quranic Arabic Corpus morphology source, runs tests, and builds a release APK. The data is generated by the build workflow because the full corpus should be fetched from attributed sources rather than reconstructed or manually typed.

## What the app includes

- Full Quran reader, all 114 surahs and 30 Juz/Paras; opens at Juz 20 by default.
- Complete ayah-level English, Urdu, and Sindhi translations, with translator/edition identifiers captured in `assets/data/data_manifest.json`.
- Arabic words are selectable. Local word morphology includes corpus root/lemma, part of speech, morphology tags, and segmented forms.
- On-demand word-by-word gloss lookup from the Quran Foundation API when internet is available; this network lookup is not bundled as copied data.
- Ayah search across Arabic and all three bundled translation fields; Arabic harakat are ignored for searching without changing the displayed Quran text.
- Persistent bookmarks, selected UI language, and adjustable Arabic text size.
- Offline reader, verse translations, search, bookmarks, and morphology after the complete APK is built. Online word-gloss lookup requires internet.
- GitHub Actions release workflow and build-time validation; no Flutter SDK is required on your personal computer.

## Build the installable APK using GitHub Actions

### 1. Create a repository

1. Download and extract this ZIP.
2. Create an empty repository named `AlQariApp` at <https://github.com/new>.
3. Open PowerShell in the extracted `AlQariApp_Full` directory and run these commands (replace `YOUR_GITHUB_USERNAME`):

```powershell
git init -b main
git add .
git commit -m "Initial full AlQariApp project"
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/AlQariApp.git
git push -u origin main
```

### 2. Run the build

1. Open your repository on GitHub.
2. Select **Actions**.
3. Choose **Build complete AlQariApp APK**.
4. Click **Run workflow** or open the run triggered by your push.
5. Wait for the run to show a green check mark. Open that run and download **AlQariApp-Complete-Release-APK** from Artifacts.
6. Extract the artifact ZIP; `app-release.apk` is the Android installer.

The workflow runs `scripts/fetch_data.py` before compiling. If any required source dataset is missing, incomplete, or has fewer than 6,236 ayat, the build intentionally fails rather than producing a demo APK.

## Build locally (optional)

Install Flutter stable and Android SDK from their official sites, then run:

```powershell
python scripts/fetch_data.py
flutter create --platforms=android --project-name=al_qari_app --org=com.alqari android_scaffold
Copy `android_scaffold/android` to the project root as `android`, then remove `android_scaffold`.
python scripts/patch_android_manifest.py
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

The generated APK is at `build\app\outputs\flutter-apk\app-release.apk`.

## Important data limitation

The bundled morphology file supplies word-level morphological annotations (root, lemma, part of speech, segmentation, and associated tags). A morphology tag is not the same as a full teacher-written sentence-level Nahw/I‘rab explanation. For that reason the app presents corpus-based analysis honestly and does not invent unsupported grammatical prose. Online word-by-word glosses are attempted through Quran Foundation API; if the API or network is unavailable, the app still displays the selected verse's translation and offline morphology.
