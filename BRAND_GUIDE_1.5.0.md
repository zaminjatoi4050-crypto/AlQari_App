# AlQari Brand Guide — v1.5.0

## Brand idea
AlQari is a Quran reading companion centered on clarity, reverence and learning. The emblem combines a mihrab-inspired arch, a crescent/star motif and an open Quran. The symbol intentionally contains no small Arabic lettering so that no generated calligraphy is mistaken for verified Quranic text.

## Palette
- Forest: `#0D3B30`
- Deep forest: `#071F1A`
- Primary green: `#155B48`
- Warm gold: `#D8B56A`
- Pale gold/page: `#FFF9E9`
- Main app surface: `#F7F5EF`

## Included files
- `assets/branding/al_qari_icon.png`: 1024×1024 icon for in-app branding.
- `assets/branding/alqari_icon_foreground.png`: transparent mark for adaptive Android icons.
- `assets/branding/alqari_icon_master.svg`: editable master vector.
- `assets/branding/al_qari_wordmark.png`: horizontal AlQari logo + English tagline, with the correct product name.
- `assets/branding/al_qari_play_store_icon_512.png`: 512×512 store listing graphic.
- `assets/branding/android/`: pre-rendered Android launcher resources by density.

## Typography
The app keeps Amiri Quran for Quranic text. The logo itself uses a geometric emblem with English wordmark; it does not render Arabic calligraphy. Verify Quranic glyph coverage and rendering on release devices.

## UI use
Use the app icon as the primary brand mark; avoid stretching the image. The gold is an accent, not a body-text color. Maintain strong text contrast in both Light and Dark themes. Do not present concept mockups as screenshots of the current app.
